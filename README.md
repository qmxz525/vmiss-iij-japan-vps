## IIJ 线路的真实表现：延迟、路由与晚高峰

IIJ 是日本本土 Tier 1 运营商（AS2497），在中国方向的核心优势是三网回程都走直连，不绕香港或新加坡。

**三网回程路由**：
- **电信回程**：东京 IIJ → ChinaTelecom AS4134 骨干网，全程 13 跳左右，延迟约 54–63ms（华南地区），北京约 62ms，上海约 71ms
- **联通回程**：IIJ → AS4837 上海联通节点，延迟约 76–110ms，北京约 80ms，上海约 60ms
- **移动回程**：IIJ → CMI（AS58453），延迟约 56–95ms，上海约 56ms，广东约 70ms；部分地区会经过 Level3 中转

**去程**：三网统一走 NTT 到日本。电信去程会先经 CN2 到香港再对接 NTT，联通走 9929，移动走 CMI。

实测平均延迟：全国 102 个探测点平均约 86ms。移动用户晚高峰表现相对最稳定。

**晚高峰的实际情况**：
- 电信晚高峰（20:00–23:00）延迟可能涨到 80–100ms，偶有 1–2% 丢包
- 联通和移动波动相对小一些
- 这是 IIJ 线路全球用户量增多后的普遍现象，不是 VMISS 单家的问题

VMISS 官方在购买页有明确提醒：IIJ 和软银线路近年整体性能有所下滑，晚高峰可能出现丢包、延迟上升、速度变慢，这是线路本身的特性，商家无法额外优化。
